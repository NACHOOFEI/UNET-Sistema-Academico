# UNET - Sistema Académico

Trabajo grupal. Frontend en Angular + backend en ASP.NET Core.

## Estructura

```
UNET-2/
├── frontend/   # Angular 19
└── backend/    # ASP.NET Core (.NET 8) - Backend.sln
```

## Requisitos

- Node.js 18+ y Angular CLI (`npm install -g @angular/cli`)
- .NET SDK 8

## Cómo correr el frontend

```
cd frontend
npm install
ng serve
```

Disponible en `http://localhost:4200`.

## Cómo correr el backend

```
cd backend
dotnet run
```

O abrir `backend/Backend.sln` en Visual Studio y ejecutar con F5.
